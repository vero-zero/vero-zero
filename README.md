2023년 11월부터 공공 · 연구기관 업무 시스템을 만들고 있습니다.
주로 Java · Spring과 Oracle로 업무 로직을 짜고, 외부 API 연동이나 데이터가 어긋나는 문제를 맡아 왔습니다.
첫 실무는 Python(Flask) 서비스를 고객사 서버로 옮기는 일이었고, 요즘은 Synapse SDK로 RAG 데이터 플러그인을 만들어 보고 있습니다.

### 최근에 한 일

- 연구자 포털에서 ScienceON(REST) · RapidILL(SOAP) 연동을 맡아, 논문 검색 API 호출을 검색 1건당 3회에서 1회로 줄였습니다.
- 학교급식 주문 시스템에서 일괄 확정 때 빠진 이력 95건을 찾아 바로잡고, 21,600건 시나리오로 다시 확인했습니다.
- 써 본 적 없던 Flask로 C# 계산 프로그램을 옮겨 고객사 서버 배포까지 마쳤습니다.
- 데이터메이커 Synapse SDK로 논문을 RAG용 청크 데이터로 바꾸는 플러그인을 만들었습니다.
